# tienda_retail_practica 
Práctica de creación de tablas e inserción de datos en ellas, en pgadmin4.

Paso 1: Crea la base de datos en pgadmin4
Paso 2: Ejecuta cada bloque de sql para crear las tablas clientes, productos y ventas.
Paso 3: Ejecuta cada bloque de sql para la inserción de datos. ¡NO OLVIDES DE USAR SELECT Para consultar si se autocompletó con los datos de forma correcta!
